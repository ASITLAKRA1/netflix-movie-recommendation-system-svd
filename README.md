# netflix-movie-recommendation-system-svd
Collaborative Filtering Movie Recommendation System using SVD (Matrix Factorization) on the Netflix Prize dataset with RMSE evaluation.

🎬 Netflix Recommendation System (SVD)
📌 Project Overview

Built a Collaborative Filtering recommendation system using the Netflix Prize dataset. The model predicts personalized movie ratings using Matrix Factorization (SVD).

Inspired by recommendation systems used at Netflix.

⚙️ Tech Stack

Python
Pandas
NumPy
Scikit-Surprise
Matplotlib / Seaborn

🧠 Approach

Data Cleaning & Preprocessing
Extracted Movie IDs from raw dataset
Removed sparse users & low-interaction movies
Quantile-based filtering
Model Building
Collaborative Filtering
Matrix Factorization (SVD)
Evaluation
RMSE

Top 5 recommended movies for User X.
